# Sales Process & Pipeline

## Pipeline Stages
| Stage | Description |
|-------|-------------|
| Lead | New lead, not yet qualified |
| Qualified | Confirmed fit, budget, timeline |
| Discovery | Requirements gathered |
| Proposal Sent | Estimate or proposal sent |
| Negotiation | In negotiation / contract review |
| Closed Won | Deal signed |

## Lead Qualification
- SQL: Stage >= Qualified, confirmed budget and timeline
- MQL: New lead, initial interest expressed

## Typical Deal Flow
1. Lead enters pipeline (inbound or outbound)
2. Qualification call
3. Discovery / requirements gathering
4. Proposal sent
5. Negotiation
6. Contract signed -> handoff to Delivery
